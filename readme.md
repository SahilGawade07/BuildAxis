# BuildAxis

A construction management application with backend API and mobile frontend.

## Structure

- **Backend**: Node.js/TypeScript Express API with MongoDB
- **Frontend**: React Native mobile app with Expo

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend/BuildAxis
npm install
npm start
```

## Features

- User authentication with JWT
- Construction project management
- Mobile-responsive interface
- RESTful API architecture

## Tech Stack

**Backend:**
- Express.js
- TypeScript
- MongoDB with Mongoose
- JWT Authentication
- bcrypt

**Frontend:**
- React Native
- Expo
- TypeScript
- React Navigation
